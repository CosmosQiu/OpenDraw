# OpenTapNow

OpenTapNow 是一个基于无限画布的 AI 工作流演示应用。你可以在画布中拖拽节点、组织素材、保存项目，并通过前端内置的演示能力体验登录、项目管理和画布编辑流程。

> **重要说明**
>
> - **当前分支仅用于演示**
> - **当前分支未接入真实后端和真实同步服务**
> - **当前可用功能全部在前端实现**
> - **数据主要保存在浏览器 localStorage / 本地导出文件中**
> - **不要用于生产环境**

## 当前分支定位

这个仓库包含 `app`、`worker`、`syncer` 等目录，但**当前正在维护的这个演示分支，实际可运行和已验证的是 `app` 前端演示应用**。

也就是说：

- `app`：当前演示入口，已可本地运行
- `worker`：仓库中保留的后端目录，**本分支未接入到当前演示流程**
- `syncer`：仓库中保留的同步服务目录，**本分支未接入到当前演示流程**

如果你只是想体验或演示当前版本，请只关注 `app`。

## 当前可用能力

- **登录页**：纯前端演示登录，使用本地会话存储
- **项目管理**：创建、重命名、复制、删除项目
- **画布编辑**：进入项目后在 tldraw 画布中编辑内容
- **本地保存**：项目列表和画布状态保存在浏览器本地存储
- **本地导出**：支持将当前项目导出为 JSON
- **演示级 AI/节点交互**：部分流程为前端占位或演示实现，便于展示 UI 和交互链路

## 不包含的能力

当前分支**不应被理解为完整产品版本**。下面这些能力在本分支中**没有正式接入或没有完成生产化**：

- 真实后端业务处理
- 真实多用户协同同步
- 真实鉴权与权限控制
- 生产级数据存储与恢复
- 生产级错误监控、审计、限流和安全治理
- 可直接上线的部署方案

## 技术栈

当前演示应用主要使用：

- React 19
- Vite 7
- TypeScript 5
- tldraw 4
- Tailwind CSS 3
- Radix UI

## 快速开始

### 环境要求

- Node.js 18+
- pnpm

### 本地启动前端演示

```bash
cd app
pnpm install
pnpm dev
```

启动后访问：

```text
http://localhost:5173
```

如果 5173 端口已被占用，Vite 会自动切换到其他可用端口，请以终端输出为准。

## 当前演示流程

启动后你可以按以下顺序体验：

1. 进入登录页
2. 使用演示账号信息登录
3. 进入项目列表页
4. 新建或打开项目
5. 进入画布页面编辑
6. 从画布返回项目列表
7. 在项目页点击“退出登录”回到登录页

## 数据存储说明

当前分支的数据存储是**前端本地演示方案**：

- 登录态：浏览器 `localStorage`
- 项目列表：浏览器 `localStorage`
- 画布内容：浏览器 `localStorage`
- 项目快照：支持本地导出 JSON

这意味着：

- 清空浏览器存储后，演示数据会丢失
- 不同浏览器之间数据不会自动同步
- 不同设备之间数据不会自动同步
- 这不是生产级持久化方案

## 生产环境警告

**这个分支不能直接用于生产环境。**

原因包括但不限于：

- 没有真实后端接入
- 没有正式鉴权体系
- 没有正式数据库持久化
- 没有可靠的多用户同步
- 部分能力仍为前端占位逻辑或演示逻辑
- 缺少生产级安全、监控、审计和容灾能力

如果你需要生产版本，应在独立分支或正式项目中补齐后端、同步服务、鉴权、存储、监控和部署体系。
